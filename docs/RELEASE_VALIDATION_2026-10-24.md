## Исправления по итогам прогона

Длинный PDF-тест успешно формировал документ, но его проверка 6500 раз заново искала строку во всём извлечённом Unicode-тексте. Стек работающего тестового процесса подтвердил эту причину задержки. Проверка заменена одним проходом регулярного выражения с точным сравнением всех номеров и их порядка: пропуски, повторы и перестановки по-прежнему обнаруживаются. После исправления полный unit-набор завершился без ошибок.

В README внутри DMG удалено устаревшее упоминание избранного. Примеры имени установщика в README приведены к текущей версии. Ошибок в рабочей логике приложения тесты не выявили.

## Воспроизводимость выпуска

Номер версии сохранён: 1.2, билд 6; macOS 13+, arm64. Для включения незакоммиченных правок создаётся отдельный локальный Git-снимок текущих исходников. `scripts/release.sh` собирает его чистый коммит и формирует DMG без изменения истории основного репозитория.

Рядом с локальным DMG сохраняются `.sha256`, `source.bundle` с точным снимком исходников и `manifest.json` с идентификаторами исходного и сборочного коммитов и результатами проверки образа. В Dropbox публикуются только DMG и `.sha256`. Подпись — существующая ad hoc, без нотарификации Apple.
