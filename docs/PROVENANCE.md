# Происхождение самостоятельного проекта

Основа: `sergeyssimonov-max/HHVacancySber`, коммит `852fc27eb225e0ec2aca556ea3ed0f195b2db15c`, чистая рабочая копия на момент переноса 16.10.2026. Это фиксированная точка функционального соответствия.

Перенесены физические копии исходников SwiftUI/ViewModel, hh.ru API, моделей, сборщика, регионального справочника, фильтров, классификации, кешей, избранного, PDF-экспорта, тестов, скриптов измерений и выпуска. В новом репозитории собственная история с первым коммитом; исходная история, remotes, worktrees, теги и настройки пользователя не импортировались.

Предметные изменения:

1. Самостоятельные проект, схема, targets, bundle ID и Application Support `HHVacancyCBR`.
2. Название `ЦБВакансии`, собственный значок «ЦБ», подписи, имена PDF и DMG.
3. Собственный подтверждённый реестр. Старые JSON работодателей и миграция их версий исключены.
4. Fixtures и идентификаторы UI-тестов адаптированы к новому периметру; проверки миграции заменены проверками её отсутствия, первого запуска и восстановления собственного списка.
5. Нумерация нового продукта начинается с 1.0 (1); CI и релизные скрипты работают только с ним.
6. Схема встроенной авторизации сохранена без изменения по прямому указанию пользователя.
7. Унаследованный UI-тест выравнивания PDF проверяет отступ содержимого окна 28 pt: AX-граница нативной кнопки зависит от macOS и на тестовом Mac имеет дополнительный внутренний отступ 8 pt. Геометрия интерфейса не изменена.

Алгоритмы сетевого клиента, сбора, дедупликации, фильтрации, классификации и PDF-вёрстки не перерабатывались. Старые отчёты о релизах и работодателях исходного продукта не переносятся как документация нового продукта. Их заменяет документация текущего состояния.

Общих изменяемых библиотек, Git submodules, абсолютных ссылок на локальные исходники и автоматической синхронизации нет. Изменение любой программы не изменяет код или пользовательские данные другой.

Сравнение каждого Swift-файла с исходной версией, включая SHA-256, записано в `SOURCE_COMPARISON.json`. Значения токенов в отчёте не выводятся.
