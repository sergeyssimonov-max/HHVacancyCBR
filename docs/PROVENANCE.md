# Происхождение проекта

HHVacancyCBR создан на основе похожего приложения для мониторинга вакансий Сбера. Для нового приложения сформирован собственный реестр Банка России и связанных организаций, введены название «ЦБВакансии» и отдельное локальное хранение данных. К hh.ru добавлен источник trudvsem.ru: у каждой вкладки свои обновление, поиск, фильтры и сохранённая выборка. PDF-экспорт дополнен вложениями исходных ответов API и контрольными суммами ГОСТ Р 34.11-2012, чтобы можно было проверить происхождение выгруженных сведений. Усилена обработка сетевых сбоев: ограничены повторы и время ожидания, а неполный сбор не заменяет последнюю полную выборку. Код и тесты упорядочены по обязанностям, подготовлены документация разработчика и проверки сборки, интерфейса, хранения и PDF.
