# Версия 1.2, сборка 6

Карточки trudvsem.ru используют общий HTML-компонент описания и кнопки перехода как hh.ru. Название работодателя выводится один раз из канонического реестра. В UI описания выводятся обязанности, требования, квалификация, образование, опыт, график, занятость, условия и социальные гарантии; исходный JSON и технические поля остаются в документированных материалах.

Полные обновления источников используют общую отменяемую очередь: второй источник ожидает завершения первого без блокирования главного потока. Последовательные запросы trudvsem.ru разнесены на 1,5 секунды; сохранены ограниченные повторы, Retry-After и тайм-ауты. Это ограничение нагрузки, а не результат измерения плавности на всех Mac.

В PDF удалён верхний повторяющийся колонтитул. Нижний номер страницы продолжается между файлами массового экспорта; каждый том по-прежнему ограничен 100 страницами вместе с реквизитами и исходными материалами.
