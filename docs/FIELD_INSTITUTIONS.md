# Категория «Полевые учреждения»

Категория независима от профессиональной специализации, работодателя и географии. Переключатель в единой верхней строке фильтров работает вместе с работодателем и регионом (AND), на обеих вкладках. Счётчик показывает распознанные вакансии текущей отфильтрованной выборки. Статистический PDF использует ту же выборку, содержит название категории и число полевых вакансий; персональный PDF содержит метку категории.

Общий `FieldInstitutionClassifier` находится в `HHVacancyCBR/HHVacancyCBR/FieldInstitutionClassifier.swift`. Он хранит признак и текстовое основание в VacancySearchResult и Codable-снимках. Старые сохранения читаются без миграции. При ленивой загрузке описания результат уточняется и сохраняется; массовой загрузки описаний нет.

Для аккаунта 47858 принимается прямое указание учреждения в названии/подразделении либо явное указание места работы в описании. Одиночные названия населённых пунктов, полевые инженеры, опыт предыдущей работы, взаимодействие с учреждениями и упоминание департамента не дают принадлежности. Для сокращений ПУ и номерных обозначений используется проверенный справочник. Это консервативный классификатор: неполные или неоднозначные сведения могут остаться нераспознанными.

Справочник `FieldInstitutionClassifier.registry` расширяется записями `FieldInstitutionRegistryEntry`: альтернативные названия, подтверждённые hh ID и URL документального основания. Названия и номера начального набора сверены 17.10.2026 по [официальному перечню Банка России](https://www.cbr.ru/psystem/field_offices/adresa-obsluzhivaniya-platezhnykh-kart/). Самостоятельные hh ID пока не подтверждены и не включены. После их добавления сборщик автоматически включает эти аккаунты в поиск, а классификатор принимает все их вакансии независимо от специализации.

Дополнительный поиск по аккаунту 47858 и тексту «полевое учреждение» выполняется без `area`, максимум две страницы по 100 кандидатов на обновление. Результаты проходят классификатор и дедупликацию по ID вакансии. Используются общие ограничения запросов, времени, повторы и обработка отмены/ограничений hh.ru. Достижение лимита отражается предупреждением о неполноте. Подтверждённые самостоятельные аккаунты ищутся без ограничения страной. Для географии вне российского дерева сохраняются исходные ID и названия hh.ru, без подмены российскими регионами.

Полнота зависит от доступных API полей, поисковой выдачи и проверенного справочника. Отсутствие метки не доказывает, что вакансия не относится к полевому учреждению.


Для trudvsem.ru применяются те же текстовые правила через `classifyWorkplace`, без преобразования вакансии в HH DTO. Сначала проверяется принадлежность к `bank_of_russia` по ИНН/ОГРН. Анализируются название, company.name, обязанности и адреса; основание содержит источник, ИНН и companycode. Вакансии остальных пяти организаций не классифицируются как полевые учреждения Банка России. Дополнительные companycode не объявляются полевыми по одному только совпадению города.
