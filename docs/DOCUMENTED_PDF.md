# Документированный PDF

На каждой вкладке доступны три самостоятельные команды:

1. «Экспорт в PDF» — полная карточка вакансии.
2. «Статистика в PDF» — агрегаты и краткий реестр текущей выборки.
3. «Все вакансии в PDF» — полные карточки всей выборки после фильтров, в выбранном порядке.

Пустая выборка не экспортируется. Состав и фильтры фиксируются до асинхронной подготовки. Изменение вкладки или фильтров не изменяет уже начатый экспорт. hh.ru при необходимости получает подробности через свой клиент, trudvsem.ru использует все содержательные поля сохранённого ответа, включая неизвестные вложенные поля. Даты создания и изменения не подменяются датой публикации. Неизвестные зарплаты не считаются нулевыми.

Общий движок сохранён в `VacanciesPDFExporter.swift`: Avenir Next с резервным шрифтом, чёрный текст, поля, номера страниц, HTML-обработка, алгоритм пагинации и проверка видимого содержимого. Сохранён лимит **100 страниц в части массового экспорта**. Расчёт теперь включает реквизиты источников и заголовки. Разделение предпочитает границы карточек; карточка длиннее лимита продолжается в следующей части с пометкой. Каждая часть содержит источник, фильтры, дату, номер части и относящиеся к её вакансиям исходные материалы. Готовые части временно хранятся на диске, сохраняются последовательно; временный каталог удаляется при завершении/ошибке/отмене.

Названия начинаются с `цбвакансии_`; массовые файлы включают источник и номера томов. Каталог выбирается один раз. Создание через `O_EXCL` исключает перезапись: занятое имя получает суффикс `_2` и далее. Это правило действует также для персональной и статистической выгрузки. Отмена не объявляется успешным экспортом, созданные данной незавершённой записью файлы убираются без удаления посторонних файлов.

## Исходные материалы

`PDFSourceEvidence` сохраняет неизменные байты JSON, разрешённые параметры GET, endpoint, время отправки и получения, HTTP-статус, размер, связанные ID и источник. Токены и заголовки авторизации не сохраняются. Архив `documented-archive-v1/observations` и прежние записи hh.ru совместимы: отсутствие поля source означает hh.ru.

При отсутствии или повреждении исходных материалов PDF содержит явное предупреждение и служебное вложение с описанием ограничения; старые снимки не превращаются в вымышленные API-ответы. Источник ответа проверяется против источника документа. Один и тот же исходный ответ включается в часть один раз. Если ответ содержит соседние вакансии, байты не вырезаются и не редактируются.

JSON вложены как `EmbeddedFiles`; они не печатаются отдельными страницами. Видимый блок проверки содержит endpoint, параметры, время, HTTP-статус, размер и ГОСТ Р 34.11-2012, 512 бит (Streebog-512). Извлеките соответствующее вложение просмотрщиком с поддержкой EmbeddedFiles и пересчитайте хеш по исходным байтам, без пересохранения JSON. Независимая проверка реализации:

```sh
python3 -m venv /tmp/streebog-check
/tmp/streebog-check/bin/pip install gostcrypto==1.2.5
/tmp/streebog-check/bin/python scripts/verify_streebog.py
```

Старые записи SHA-256 читаются для совместимости; новые ответы хешируются только Streebog-512. Служебный SHA-256 в генераторе имени статистического файла не является хешем исходных материалов.

Совпадение хеша подтверждает только согласованность вложенных байтов и контрольной суммы и помогает обнаружить случайное повреждение. Оно не доказывает происхождение ответа, время его получения или неизменность при намеренном изменении файла и хеша. Документы не заявляют заверение оператором портала, работодателем или Банком России. Название программы, версия и локальные пути в содержимое документа не добавляются.

Архив исходных ответов ограничен 30 днями и приблизительно 512 МиБ (без учёта текущего записываемого ответа). Проверка выполняется при сетевом обращении не чаще раза в час. Старые материалы удаляются первыми; сохранённые карточки остаются доступны, а PDF при утрате материала содержит предупреждение. Для ручной очистки можно удалить каталог `documented-archive-v1/observations` в Application Support контейнера приложения.
