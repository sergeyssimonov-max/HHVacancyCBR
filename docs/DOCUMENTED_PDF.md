# PDF-выгрузки вакансий

Карточка вакансии, реестр и избранное формируются в PDF с единым оформлением: Avenir Next с запасным шрифтом, чёрный текст, единые интервалы и полужирное начертание преимущественно для заголовков. В тексте показаны читаемые сведения о вакансиях. Исходные JSON-ответы hh.ru не печатаются страницами: при наличии они прикрепляются к PDF как EmbeddedFiles без изменения исходных байтов. Для просмотра вложений нужен PDF-просмотрщик, поддерживающий EmbeddedFiles. ZIP-выгрузки нет.

Видимый документ содержит источник и только выбранные фильтры. У каждой вакансии есть название, идентификатор и дата публикации, работодатель и его идентификатор, ссылка на объявление и реквизит приёма откликов. Статус приводится при наличии подтверждённых данных hh.ru. В документах кратко объясняется, что идентификаторы hh.ru помогают найти объявление и карточку работодателя. Собственные номера PDF и записей источника не выводятся и не прикладываются к PDF. Название приложения, ссылка на него и версия сборки в PDF не выводятся.

## Источник и хеш

Новые ответы `api.hh.ru/vacancies` сохраняются локально в исходных байтах вместе с временем получения, адресом запроса, разрешёнными параметрами, HTTP-статусом, размером и хешем. Данные авторизации и заголовки не записываются. Исходный ответ поисковой выдачи может содержать и соседние вакансии: выборочная правка ответа изменила бы проверяемые байты. Старые сохранённые вакансии остаются доступными, но исходные ответы для них задним числом не создаются.

Для каждого сохранённого ответа PDF содержит блок проверки и полное название: ГОСТ Р 34.11-2012 «Информационная технология. Криптографическая защита информации. Функция хэширования», вариант 512 бит. Совпадение хеша при повторном расчёте подтверждает неизменность приложенных исходных байтов ответа. Исходный код реализации и лицензия зафиксированы в `Vendor/Streebog/PROVENANCE.md`; независимое сравнение с другой реализацией выполняет `scripts/verify_streebog.py`.

Исходные ответы для новых выгрузок находятся в `Application Support/HHVacancyCBR/documented-archive-v1/observations`. Путь сохранён для совместимости с ранее полученными исходными данными. Приложение больше не создаёт каталогов архивных PDF, истории для просмотра и снимков веб-страниц. Ранее сохранённые пользовательские файлы автоматически не удаляются.
