# Надёжность и ресурсы

Изменения после сборки 1.2 (6):

- Очередь полных обновлений больше не просыпается каждые 200 мс. Ожидающие задачи получают continuation в порядке регистрации; отмена удаляет ожидающего, а отмена на границе передачи освобождает разрешение для следующего. Все переходы состояния изолированы MainActor.
- Список trudvsem.ru вычисляется один раз на набор данных и фильтров. Кэш сбрасывается при замене результатов и изменении любого фильтра или сортировки. Дата разбирается один раз на вакансию за пересчёт вместо многократного разбора внутри сортировки. Кэш содержит только текущую выборку, а не историю комбинаций фильтров.
- Справочник регионов строится без группирования полных массивов вакансий и кэшируется до изменения результатов.
- Фильтры hh.ru выполняются одним проходом, без промежуточных массивов для каждого условия.
- В PDF введён autoreleasepool на страницу, ограничивающий срок жизни временных объектов AppKit/TextKit. Готовые PDF-данные и массив исходных страниц всё ещё находятся в памяти: потоковая перезапись формата не выполнялась.

Сохранены порядок сортировки, фильтрация, исходные материалы PDF, сквозная нумерация, лимит страниц и атомарная публикация снимков. Синхронный участок фиксации снимка оставлен без изменений, чтобы не ввести гонку отмены между сохранением и публикацией. Отсутствие сбоев при любых данных и на любом оборудовании не гарантируется.

Проверки: полный unit-прогон с новыми сценариями отмены/передачи очереди и инвалидирования кэша; строгая Release-сборка; локальный синтетический PDF-бенчмарк. Численных обещаний ускорения относительно предыдущего билда нет: для них требуется многократное сравнение одинаковых нагрузок на одном оборудовании.

Контрольный замер `pdf 100` на текущем Mac: 221 страница, 532805 байт PDF, 5,67 с wall-clock, 5,37 с CPU, peak RSS 45252608 байт (43,2 МиБ), 20 параллельных mock-запросов. Максимальный интервал heartbeat harness 0,658 с включает его собственные проверки; это не замер задержки SwiftUI. Замер выполнен после завершения сборок и unit-тестов, без живой сети.
