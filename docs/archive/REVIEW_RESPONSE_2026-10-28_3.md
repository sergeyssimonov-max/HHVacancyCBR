# Ответ на третью рецензию

Рецензия сопоставлена с кодом версии 1.3 (11). Этот документ фиксирует результат проверки и не утверждает, что все упомянутые в рецензиях вопросы закрыты.

- Р-4: замечание об отсутствии статей 71 ГПК РФ и 75 АПК РФ принято. В PDF добавлены ссылки на нормы о письменных доказательствах, а также указана возможность нотариального обеспечения доказательств. Допустимость и оценка документов не объявляются автоматическими; PDF не является нотариальным протоколом. Источники и пределы утверждений приведены в `DOCUMENTED_PDF.md`.
- Н-1: ошибка записи исходного ответа trudvsem.ru больше не превращает успешный ответ API в неудачный запрос; при отсутствии материала PDF содержит предупреждение.
- Н-3: при обновлении встроенного реестра недостающие записи добавляются, а при изменении реквизитов подтверждённые коды сбрасываются. Загрузка сохранённого снимка отделена от чтения конфигурации.
- Р-1: общая шапка и примечание не повторяются перед каждой карточкой hh.ru в массовой выгрузке.
- Р-2: содержимое тома размечается совместно с заголовком, поэтому повторная пагинация учитывает не только первую из ранее размеченных страниц. Проверка сохранности текста и ограничения в 100 страниц сохранена.
- Р-3: число страниц блока проверки кешируется по составу наблюдений и признаку отсутствующих материалов; изменение количества вакансий при тех же ответах API больше не вызывает его повторную разметку. При каждом новом наборе наблюдений разметка по-прежнему выполняется, поэтому вопрос масштабирования полностью не закрыт.
- Н-8: целое число рабочих мест выводится без дробной части. Н-13: исправлены инвалидирование кеша и сопоставление ключей организаций. Р-5: период статистики сортируется по датам, а не по строкам. Р-7: неоднозначный вариант ключа с лигатурой объяснён в коде.
- Т-1: в команду сборки автономного стенда добавлены необходимые исходные файлы. Сообщение прежнего ответа о замене системного HTML-импортера исправлено: он по-прежнему используется.

Остались отдельными задачами: системный HTML-импортер и производительность массового экспорта (Н-2, Р-3), поведение панели сохранения в песочнице (Н-4), частичные сбои получения подробностей (Н-5), политика публикации неполной выборки (Н-6), сериализация записи снимка (Н-14), остальные замечания к тестам и интерфейсу. Предложения о контактах, типографике и дополнительных настройках требуют отдельной продуктовой оценки. Публикация неполной выборки и режим без перезаписи затрагивают действующее поведение и не меняются без отдельной проверки последствий.
