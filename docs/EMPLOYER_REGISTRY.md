# Реестр организаций

Системный реестр независим от профилей порталов. Фильтры обеих вкладок всегда содержат шесть организаций; дополнительные пользовательские аккаунты hh.ru сохраняются отдельно. Надзор Банка России и сходство названия не подтверждают принадлежность.

Основания: [Банк России](https://www.cbr.ru/), [РОСИНКАС](https://www.rosinkas.ru/info), [история НСПК](https://www.cbr.ru/about_br/history/), [РНПК на hh.ru](https://hh.ru/employer/2608647), [учреждение НСИС](https://www.cbr.ru/press/event/?id=14592), [НСИС](https://nsis.ru/), [НСИС на hh.ru](https://hh.ru/employer/9942121), [финансовое оздоровление](https://www.cbr.ru/banking_sector/PrBankrot/), [УК ФКБС](https://amfbc.ru/).

22.10.2026 официальный API hh.ru подтвердил имя НСИС и `site_url=https://nsis.ru/`. Ограниченный поиск УК ФКБС (два запроса названия, одна карточка кандидата) вернул `12644406`, имя «УК ФКБС», `site_url=http://amfbc.ru`, ноль открытых вакансий. Полное название не дало результатов. Карточка кандидата не содержит ИНН/ОГРН и описания. Совпадение сайта и сокращения зафиксировано, но юридическая идентичность дополнительно не подтверждена: ID **не включён** в рабочую конфигурацию. Это не утверждение об отсутствии профиля.

На trudvsem.ru поиск идёт по собственному ИНН каждой организации. Возвращённый ИНН обязан совпасть; при наличии ОГРН он тоже проверяется. Разные companycode одного ИНН остаются разными подразделениями. Проверенные в успешном сборе коды сохраняются в отдельном `employers-trudvsem.json`; произвольный текст названия не используется для привязки.

Живая проверка 22.10.2026: для Банка России получены companycode `50cb3090-72ea-11ec-9eb2-550ed7335bbe`, `6c9e4a20-b0cd-11ec-bdf7-550ed7335bbe`, `87677310-841b-11ec-aae7-550ed7335bbe`; для НСИС — `1237700279508`. У НСПК, РНПК и УК ФКБС API вернул успешные пустые списки. Запрос РОСИНКАС завершился тайм-аутом; отсутствие вакансий по нему не установлено. Эти результаты не являются константами приложения.

`employers.json` версии 1 мигрирует в версию 2: существующие записи и правки сохраняются, отсутствующие системные аккаунты добавляются без дублей, запись атомарна. Повторная миграция не меняет файл. Повреждённый JSON или будущая версия не сбрасываются. Дополнительный hh-аккаунт может иметь `organizationKey`, `verifiedAt`, `verificationSource`; принадлежность должна подтверждаться до внесения записи.

Материалы СПАРК не включены в репозиторий. Полнота охвата всех подразделений не заявляется.


Повторная ограниченная проверка: `python3 scripts/discover_uk_fkbs.py`. Скрипт выполняет ровно два поисковых запроса и не более пяти запросов карточек, использует существующую авторизацию, не печатает токен и не меняет реестр. Для включения кандидата необходимо подтвердить соответствие ИНН 7714997584 / ОГРН 1177746688130 и документировать основание, затем явно внести ID, organizationKey, verificationSource и verifiedAt в конфигурацию. Совпадение сокращения не является автоматическим подтверждением.
