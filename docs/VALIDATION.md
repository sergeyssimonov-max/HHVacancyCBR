## Воспроизведение выпуска

`scripts/release.sh` собирает экспорт чистого коммита из независимого временного каталога, со строгой конкурентностью и предупреждениями как ошибками. В процессе проверяются подпись, hardened runtime, sandbox, сетевое разрешение и доступ к выбранным пользователем файлам. `get-task-allow` в Release запрещён. DMG проверяется `hdiutil verify`, рядом сохраняется SHA-256. Таким образом, исходная рабочая копия не является входом сборки.

## Границы проверки

- Прямые запросы к `api.hh.ru` из среды запуска команд завершились ошибкой DNS `nodename nor servname provided, or not known`. Живую загрузку и действительность токена на дату проверки подтвердить не удалось; сетевой клиент проверен перенесёнными тестами с контролируемыми ответами. Работодатели подтверждены веб-страницами, перечисленными в реестре.
- Независимость установки подтверждена различными идентификаторами и хранилищами. Реальная установка/удаление второй программы на другом Mac не выполнялись.
- Workflow GitHub подготовлен, но удалённые CI-прогоны не выполнялись. Создание удалённого репозитория остановлено автоматической проверкой разрешений до дополнительного подтверждения пользователя о публикации встроенного токена по указанному адресу. Локальный Git-репозиторий полностью автономен.
- По умолчанию артефакт выпуска имеет подпись ad hoc; Apple Developer ID и нотарификация в этой среде не настроены.
