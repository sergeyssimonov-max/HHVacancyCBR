## Текущий стабильный релиз

[GitHub Release v1.3.4-15](https://github.com/sergeyssimonov-max/HHVacancyCBR/releases/tag/v1.3.4-15) содержит установщик и `.sha256`. Его исходный commit определяется аннотированным тегом и README внутри DMG. Релизный SHA, CI, журнал упаковки и хеши опубликованного файла фиксируются в описании выпуска; ссылка на артефакт Actions сама по себе не означает опубликованный релиз.

Локальный ранее установленный DMG из 633d51f и новый пакет GitHub могут иметь одинаковую версию 1.3.4 (15), но разные commit происхождения, toolchain и SHA-256. Проверяйте каждый файл по его собственной контрольной сумме. Оформление GitHub Release не заменяет установленное приложение и не подтверждает живые API для нового пакета.

## Доступность доказательств

Небольшие сводки — в [validation/](validation/README.md). Baseline, diff, большие xcresult, PDF и резервные копии сохранены вне репозитория в проверенном локальном архиве владельца. Архивирование не означает повторного исполнения исторических тестов. Октябрьские отчёты перенесены в [archive/](archive/README.md) и сохраняют прежние даты и ограничения.

## Существенные ограничения

- Живые API внешние: тайм-аут, ограничение доступа и изменение выдачи возможны. Неполный сбор не считается новым полным снимком.
- Неподтверждённый профиль УК ФКБС не включён в hh.ru; список организаций источников различается.
- Сохранены известное ограничение синтетического `search 1000` и исходная стоимость обработки 10 000 вакансий; подробности в отчёте о рефакторинге.
- Подпись выпуска ad hoc, без Developer ID и нотарификации Apple. Установка на другом Mac не подтверждена этими локальными материалами.
- Лицензия основного проекта не назначена. Уведомления Streebog сохранены; разрешённое владельцем использование встроенного токена не заменяет лицензию кода.
