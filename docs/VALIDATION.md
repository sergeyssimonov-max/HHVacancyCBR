## Существенные ограничения

- Живые API внешние: тайм-аут, ограничение доступа и изменение выдачи возможны. Неполный сбор не считается новым полным снимком.
- Неподтверждённый профиль УК ФКБС не включён в hh.ru; список организаций источников различается.
- Сохранены известное ограничение синтетического `search 1000` и исходная стоимость обработки 10 000 вакансий; подробности в отчёте о рефакторинге.
- Подпись выпуска ad hoc, без Developer ID и нотарификации Apple. Установка на другом Mac не подтверждена этими локальными материалами.
- Лицензия основного проекта не назначена. Уведомления Streebog сохранены; разрешённое владельцем использование встроенного токена не заменяет лицензию кода.
