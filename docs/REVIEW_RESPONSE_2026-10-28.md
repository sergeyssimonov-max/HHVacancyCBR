# Разбор внешней рецензии от 28.10.2026

Рецензия рассмотрена относительно текущей версии с двумя независимыми источниками. Её объект 26105b8 существенно отличается от текущего дерева. Предложения из рецензии не являются обязательными требованиями: ниже перечислены принятые изменения и ограничения.

## Принято

- P0-2: запись материалов hh.ru вынесена за пределы сетевого gate, сбой записи не отменяет успешный поиск. Хранилище внедряется конструктором.
- P0-3: архив ограничен 30 днями и примерно 512 МиБ; очистка не чаще раза в час при получении ответа. Это альтернативная политика вместо удаления всех материалов, не связанных с текущим снимком: сохраняет возможность выгрузки недавно просмотренных карточек двух источников.
- P0-4: отсутствие или повреждение материала не блокирует PDF. Документ содержит предупреждение; повреждённые материалы не считаются проверенными. Несоответствие источника и несвязанные ответы по-прежнему отклоняются.
- P0-5: оставшееся построение словаря результатов защищено от повторов. Избранное удалено из текущего продукта, замечания к его хранилищу неприменимы.
- P0-6: уточнены пределы контрольной суммы в PDF и документации.
- P1-1/P1-9: результат классификации копируется при изменении состояния карточки; при получении новых данных выполняется новая оценка, прежнее положительное решение не подменяет отрицательное.
- P1-2: кэш фильтрации и сортировки hh.ru инвалидируется при изменении данных и фильтров; аналогичный кэш trudvsem.ru уже существует.
- P1-3: сохранение деталей отложено на секунду и выполняется вне главного актора; загрузка снимка также вынесена с него.
- P1-4: середина временного разбиения выровнена по пяти минутам, добавлена защита от нулевого продвижения.
- P1-6: основной регион сохраняется у удалённой вакансии и при нескольких регионах.
- P1-8: устранено двойное декодирование amp, добавлены типографские сущности.
- P2 интерфейс: текстовый поиск hh.ru по загруженным названию и описанию, выбор имеющихся сортировок, открытие ссылок описания, повторный экспорт карточки.
- P2 архитектура: версия User-Agent берётся из bundle; уведомление о лицензии Streebog включено в DMG; подпись приложения проверяется после упаковки.
- P2 тесты/CI: изоляция стандартного кеша регионов XCTest, синхронизация доступа к глобальному обработчику URLProtocol, таймаут unit-job, минимальные права CI, отключено сохранение credentials checkout, строгая конкурентность в проекте.

## Уже реализовано / не относится к текущей версии

P1-10: встроенные организации добавляются при чтении конфигурации, пользовательские записи сохраняются. P1-11 и замечания к миграции избранного неприменимы. P1-13: текущий конвертер PDF уже использует собственный ограниченный HTML parser вместо системного HTML importer. Разбор Retry-After поддерживает HTTP-date. Ошибки экспорта уже содержат localizedDescription. Текстовый поиск/сортировка trudvsem.ru уже реализованы. Повторный разбор исходных байтов при встраивании ранее устранён.

## Ограничения и дальнейшие задачи

Этот патч не означает реализацию каждого предложения рецензента. Не включены крупное разделение ViewModel, каталог локализации, замена всех иконок, дополнительные сортировки по зарплате/работодателю, динамическая высота WebView, полная переработка тестовых фикстур и таймеров, фиксация Xcode/actions SHA, смена словарного разбиения schedule, восстановление повреждённых снимков с UI. Эти пункты остаются самостоятельной работой. Предложение заменить полный снимок неполным не принято в этом патче: сохраняется существующая политика публикации только полного сбора; возраст сохранённого снимка виден пользователю.

Проверки: 23 Python-теста, verify_independence, автономный reliability harness, unit-тесты Xcode. Изменения существовавшего рабочего дерева включены в выпуск вместе с доработками этой рецензии по поручению владельца.
