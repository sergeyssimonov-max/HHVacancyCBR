# Порядок работы с Git

Работайте непосредственно в ветке `main`. Не создавайте дополнительные ветки без отдельного запроса владельца.

# Геометрия интерфейса

Для обеих вкладок используйте общие размеры элементов и отступы панелей. Выравнивайте видимые края, а не только рамки контейнеров; проверяйте оба края и высоту элементов при изменении геометрии. Свободную ширину отдавайте элементам управления, сохраняя компактные одинаковые отступы.
